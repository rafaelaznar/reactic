# Welcome to the Local Wiki

This is a **client-side wiki** that reads Markdown files directly from your local disk.

## Featuressssssdddd11122233344455555666777

- **Markdown Rendering** — Pages are written in Markdown and rendered beautifully
- **Navigation** — Breadcrumb trails and relative links between pages
- **Table of Contents** — Auto-generated from page headings
- **Page Index** — Tree view of all pages in the wiki
- **Code Highlighting** — Syntax highlighting for code blocks
- **No Server Needed** — Everything runs in the browser

## Directory Structure

Pages mirror the file hierarchy inside your wiki folder:

| File                    | Page Path           |
