Ejercicios progresivos de Tic Tac Toe con React y JavaScript vanilla

Tres en Raya — implementación clásica del Tic Tac Toe:

estado compartido con useState, historial de movimientos, navegación entre turnos, detección de ganador con líneas ganadoras resaltadas, control de empate y botón de reinicio. Se recorren ocho versiones que evolucionan el stack de estilos y tipado.

  • tic01.html - Tic Tac Toe — CSS vanilla
    CSS Babel React + JSX con estilos CSS clásicos sin librerías externas
    useState
  • tic02.html - Tic Tac Toe — Tailwind
    Tailwind Babel Mismo juego migrado a utilidades Tailwind mediante CDN
    useState
  • tic03.html - Tic Tac Toe — TypeScript + Tailwind
    TypeScript Tailwind Tipado estático con interfaces, genéricos y compilación TS en el navegador
    useState
  • tic04.html - Tic Tac Toe — Bootstrap + TypeScript
    Bootstrap TypeScript Misma lógica con Bootstrap 5 vía CDN y tipado estático con TypeScript
    useState
  • tic05.html - Tic Tac Toe — JavaScript puro
    CSS Sin librerías ni CDN. Toda la lógica con DOM API vanilla, historial de movimientos y detección de ganador
    sin hooks (DOM vanilla)
  • tic06.html - Tic Tac Toe — Reactivo + Declarativo
    CSS Mini framework reactivo propio: h() (vdom), atom (estado reactivo), componentes puros sin CDN
    atom (reactividad propia)
  • tic07.html - Tic Tac Toe — Preact + Bootstrap
    Bootstrap Babel Preact CDN en lugar de React, mismo JSX con Bootstrap 5
    useState (Preact)
  • tic08.html - Tic Tac Toe — Preact sin JSX
    Bootstrap Preact con h() directo, sin Babel ni JSX, Bootstrap 5
    useState (Preact)
  • tic09.html - Tic Tac Toe — Preact + HTM
    Bootstrap HTM Preact con htm (tagged templates), sin Babel ni JSX, Bootstrap 5
    useState (Preact)

ButtonApp — componente contador que abre un modal de Bootstrap con cada pulsación, usando useState y useCallback.

  • button01.html - ButtonApp — Bootstrap + React
    Bootstrap Babel Contador con modal Bootstrap, useState y useCallback
    useState useCallback

Matriz Aleatoria — generación de matriz de n filas con datos de distinto tipo:

columnas de tipo string, fecha, decimal, entero y booleano generadas aleatoriamente, mostradas en tabla con estadísticas de resumen.

  • matrix01.html - Matriz Aleatoria — Preact + Bootstrap
    Bootstrap Preact con h() directo, sin Babel ni JSX, Bootstrap 5
    useState useCallback useMemo (Preact)
  • matrix02.html - Matriz Aleatoria — React + JSX
    Bootstrap Babel React 18 UMD + JSX con Babel standalone, Bootstrap 5
    useState useCallback useMemo
  • matrix03.html - Matriz Aleatoria — React + JSX (CRUD)
    Bootstrap Babel CRUD completo, ordenación por columnas, filas de totales/medias, modal Bootstrap
    useState useCallback useMemo

Laberinto — generación y resolución de laberintos con React:

algoritmo recursive backtracker para generar el laberinto, BFS (amplitud) y DFS (profundidad) para resolverlo, con dibujo en canvas y medición de tiempo de ejecución.

  • lab01.html - Laberinto — Bootstrap + React
    Bootstrap Babel Generación con recursive backtracker, solución BFS/DFS, dibujo en canvas
    useState useCallback useRef useMemo
  • lb02.html - Laberinto — Framework reactivo propio
    CSS Misma lógica con h(), atom y componentes puros; sin CDNs
    atom (reactividad propia)
